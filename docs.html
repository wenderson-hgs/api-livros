📚 API de Livros

API REST completa: CRUD, autenticação por token JWT, paginação, busca e validação detalhada. Feita em Node.js puro — zero dependências.

Node ≥ 18 0 dependências JWT · HMAC-SHA256 Testes automatizados
URL base: http://localhost:3000

Autenticação

1. Troque suas credenciais por um token:

2. Envie o token em todas as rotas protegidas:

Authorization: Bearer <token>

sem token — as rotas 🔒 devolvem 401

Endpoints

GET/health— status do serviço

Público. Informa uptime e quantidade de livros cadastrados.

resposta
{ "status": "ok", "uptime": 42, "livrosCadastrados": 4 }
POST/login— credenciais → token

Público. Usuário demo: admin / admin123. Token expira em 1 hora.

corpo
{ "usuario": "admin", "senha": "admin123" }
resposta
{ "token": "eyJhbGciOi…", "expiraEm": "60 min" }
GET/livros— lista, pagina e busca

Público. Paginação ?page (≥1) e ?limite (1–50); filtro ?busca (título/autor) e ?genero (exato).

exemplo
GET /livros?busca=machado&limite=5&page=1
resposta
{
  "pagina": 1, "limite": 5, "total": 1, "totalPaginas": 1,
  "itens": [ { "id": "…", "titulo": "Dom Casmurro", "autor": "Machado de Assis", "ano": 1899, "genero": "Literatura" } ]
}
GET/livros/:id— detalhe

Público. 200 com o livro ou 404 se o id não existir.

POST/livros🔒 token— cria livro

Validação: titulo, autor e genero (≥2 caracteres) e ano (1450 – ano atual+1). Falha → 422 com erros campo a campo.

corpo
{ "titulo": "O Cortiço", "autor": "Aluísio Azevedo", "ano": 1890, "genero": "Literatura" }
resposta 201
{ "id": "…", "titulo": "O Cortiço", "autor": "Aluísio Azevedo", "ano": 1890, "genero": "Literatura", "criadoPor": "admin" }
PUT/livros/:id🔒 token— atualização parcial

Envie apenas os campos que quer mudar — o restante é preservado.

corpo
{ "ano": 1891 }
DELETE/livros/:id🔒 token— remove

200 com o título removido, ou 404.

resposta
{ "removido": "O Cortiço", "id": "…" }

Testador interativo
